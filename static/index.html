AON

> self-hosted dev agent

Memory

Episodes AON remembers. Only recent active ones are injected; the rest are searched on demand. Mark outdated or delete to curate.

Documents

AON searches these files by meaning and by exact words, and adds the relevant passages to its answers. Text, code, Markdown, HTML, Word (.docx) and PDF with a text layer, up to 20 MB each. Files you attach in chat are added here too.

Skills

Reusable procedure packs AON can read and author with write_skill. Click a skill to view its files and run evals.

MCP servers

Connect MCP servers (stdio). Their tools become AON tools; their prompts become skills. Adding a server runs the command you provide.

MCP data from Glama
The MCP hub reads the Glama directory through the Glama API, which needs a free API key. Create one at glama.ai/settings/api-keys and paste it here. It is stored on the AON server only.

Settings

Guidance only — editing this cannot disable the approval gate. Applies to new runs. Endpoint: /api/system-prompt
AON is a self-hosted dev agent. Read-only tools (read, list, search, fetch) run freely; shell commands and file writes require your explicit approval. Guardrails — the approval gate, path confinement, the bounded executor, and the Telegram allowlist — are fixed and cannot be edited from this UI.
